# STM32F407 最小系统板

> 一块自己画、自己焊、自己点亮的四层板：从原理图、PCB、焊接调试到串口上位机，完整走通 STM32 最小系统。

## 1. 项目概述

基于 **STM32F407** 的最小系统板，包含主控、晶振、复位、BOOT、电源、SWD 下载口与基础外设接口。项目重点不是“画一块板”，而是把 **原理图 → 四层 PCB → 焊接 → 上电 → 下载 → 外设点亮 → 上位机通信** 整条链路独立走完。

| 项目 | 内容 |
| --- | --- |
| 主控 | STM32F407 |
| PCB | 四层板 |
| 下载调试 | SWD（ST-Link + OpenOCD） |
| 工具链 | Keil、ARM-GCC、CMake、OpenOCD |
| 上位机 | Python 串口工具 |

## 2. 硬件设计

- **最小系统**：电源、复位、晶振、BOOT 配置、SWD 接口。
- **四层板**：布局时重点处理电源与地平面，保证关键信号有稳定的参考。
- **焊接**：独立完成贴片与插件焊接，上电前先检查电源轨与短路。

## 3. 工具链与调试

### 3.1 两套编译链路

| 链路 | 用途 |
| --- | --- |
| Keil MDK | 日常开发、在线调试 |
| ARM-GCC + CMake + OpenOCD | 命令行构建与开源工具链验证 |

用 OpenOCD 通过 **SWD** 完成下载与调试，配合芯片手册核对寄存器配置。

### 3.2 上电调试顺序

1. 目视检查焊接，重点看电源芯片与 MCU 引脚是否连锡；
2. 万用表测 3.3V / 5V 电源轨与短路；
3. 接 ST-Link，确认能识别芯片 ID；
4. 下载点灯程序，验证时钟与 GPIO；
5. 逐个验证 UART、I2C、SPI 等外设。

## 4. 通信与上位机

- 在 MCU 侧实现 **串口环形缓冲区**，避免中断收发丢数据；
- 设计简单的**指令解析框架**，上位机发指令、MCU 回数据；
- 用 **Python** 做串口数据采集与可视化，方便观察外设输出。

```text
上位机 (Python)  ──UART──>  环形缓冲区  ──>  指令解析  ──>  外设动作
       ↑                                                        │
       └──────────────────  数据上报  <──────────────────────────┘
```

## 5. 技术栈

`STM32F407` · `C` · `四层 PCB` · `Altium Designer` · `Keil` · `ARM-GCC` · `CMake` · `OpenOCD` · `SWD` · `UART` · `Python`

## 6. 复盘

- 四层板比两层板多出来的不是“层数”，而是电源和地的可控性。
- 两套工具链都跑通后，换电脑、换系统不再被 Keil 绑死。
- 环形缓冲区是嵌入式串口通信的基本功，与 FOC 项目中 UART DMA 上报的思路一致。
